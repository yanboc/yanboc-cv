# 简历信息清单

> **怎么用**
> 1. 按提示填写；**空着 / 删掉整段 / 写「无」= 不需要**该项或该模块。
> 2. 可复制的块（教育、论文、项目等）按需多复制几份；整类一块都不填 → 生成时自动关闭该模块。
> 3. 填完后回复 **「确认」**（或「按这份生成」），agent 会写入 HTML 并请你预览微调。
> 4. 本文件建议保存在项目根目录为 `cv-info.md`，以后改简历优先改这里再同步。
